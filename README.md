# 長者慢性病互動教學簡報

社區據點最常開的 12 個慢性病主題，做成**講師投影帶團體**的互動簡報。
每一個主題都是一堂完整的課：24 頁、9 個計分互動（含電影法看影片）。
單一 HTML、免安裝、可離線（影片段落需要網路）。

**線上使用**：<https://mattsue1003.github.io/elder-chronic-disease-decks/>

## 每一堂課的骨架

四個提問貫穿全場，12 個主題共用同一套架構，長輩上第二堂就知道節奏：

1. **我能了解什麼** — 這個病在身體裡發生什麼事、台灣現況、**為什麼會發生**
2. **控制好對誰有幫助** — 對自己、對家人、對社區與國家
3. **我能做什麼** — 明天就做得到的**預防**行動，最後一件是只有長輩做得到的傳承
4. **我能得到什麼** — 台灣實際可用的資源、權益、給付、專線

另外含 **不控制的風險**（併發症數字）與 **發生了怎麼辦**（處理步驟排序）。

## 操作方式

用電腦或平板開啟 `index.html`，點主題進去，投影出去就能上課。
畫面會依投影幕比例自動決定欄數，再把每一格的字放到最大，不需要調整。

| 按鍵 | 功能 |
|---|---|
| `←` `→` `空白鍵` | 換頁 |
| `N` | 講師提示（這一頁怎麼帶、在哪停、問什麼） |
| `S` | 音效開關 |
| `T` | 搶答計時 |
| `F` | 全螢幕 |
| `D` | 排版診斷（回報畫面問題時用） |

答對、答錯、找到問題、拿到星星都有提示音；音效是網頁自己合成的，不需要外部檔案，離線一樣有聲音。

## 使用前必做

1. **第 18 頁的資源要換成授課鄉鎮的實際據點**（衛生所、關懷據點、失智共照中心、里長），簡報上只放全國性專線。
2. **電影法的影片課前先試播一次**。部分頻道關閉內嵌會顯示「錯誤 153」，按視窗下方「在 YouTube 開啟大畫面」即可；現場沒網路就先下載，或用畫面下方的關鍵字現場搜尋。
3. **政策與統計數字逐年變動**（成人預防保健的年齡與頻率、健保給付條件、十大死因排名、盛行率）。各頁下方 `資料來源` 與講師提示都標了年份，開課前核對最新公告。
4. 「顧眼睛顧耳朵」的電影法只放了兩支影片——聽力段落缺合適的官方衛教片，請自行補一支，或改由講師示範氣音唸「6-1-9」的聽力篩檢做法。
5. **失智症與老年憂鬱這兩堂要留意台下組成**，可能就坐著輕度認知障礙的長輩或家屬。帶風險數字那一頁前先說明「不是要嚇大家」。憂鬱那一堂課後若有長輩表達強烈負面情緒，請個別關心並連結衛生所或身心科，不要在團體中公開討論。

## 內容原則

- 全系列文字為國語；只有第 3 頁的暖身俗諺填空保留台灣俚語，那是體驗遊戲環節，講師可以用台語唸。
- 不給藥物劑量、不建議自行停藥或改藥、不保證療效；急症一律導向 119。
- 長輩是有經驗的人，不是被教育的對象——全程不恐嚇、不說教、不標籤化。

## 怎麼改內容

每個主題檔案最上方是一個 `DECK` 物件，教案內容全部在裡面（標題、卡片文字、題目、答案、講師提示、資料來源）。
**改內容＝改 `DECK`，不用動下面的引擎程式。** 排版與字級會自動重算。

## 怎麼發布到 GitHub Pages

1. 建一個 repository（例如 `elder-chronic-disease-decks`），把這個資料夾裡的檔案全部放進去。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，Save。
3. 等一兩分鐘，網址是 `https://<你的帳號>.github.io/<repo 名稱>/`。
